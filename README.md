# yazi-nofar — форк моего конфига yazi без FAR-режима

Копия рабочего `~/.config/yazi` (со всеми правками, включая `y` = копирование
путей в буфер), из которой вырезаны FAR-раскладка и её плагины: `far-mode`,
`far-menu`, `far-tree`, `keymap-far.toml`, переключатель раскладки в попапе `F`
и перезапуск процесса ради смены режима. Сам бинарник yazi не пересобирается:
FAR-режим живёт в конфиге, а не в приложении.

```
./install.sh            # поставить команду yz (рабочий ~/.config/yazi не трогается)
./install.sh --uninstall
yz [путь]               # запуск на конфиге из ./config
```

Раскладка одна — vim-подобная (`keymap.toml`). Каталог, в котором вышли,
подхватывается текущей сессией fish (функция `yz.fish`).
